# Conveyor Belt PLC Sim

## Project Owner

Nathaniel Janney
natej24@vt.edu

## Project Overview

Perform a successful conveyor belt simulation with a PLC
Sort objects into accept or reject bins
System log a digital report that will be sent to an arduino


## What I Hope to Learn

Ladder Logic/PLC coding
PLC wiring
Implementing Sensors
Mechatronics
PLC data communication


## Design and Implementation

I will use mini boxes as the test cases
The simulation will check for deformities (some of the boxes will be intentionally altered)
If the box is clear it will go into the accept bin
If it has a deformity the conveyor will pause an actuator will push it out to the reject bin
To ensure a valid system the order of the boxes will be randomized before demonstration
First sensor will be a limit switch
Fall + Spring Semester Project
